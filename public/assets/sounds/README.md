# Custom Sounds Directory 🎵

Drop your custom sound files directly into this directory!

The game will automatically detect and play these audio files if present:

- `flap.mp3` - Sound played whenever Punju flaps / flies up (e.g. Balayya dialogue, rooster crow, jet whoosh)
- `point.mp3` - Sound played when passing an obstacle or collecting corn
- `hit.mp3` - Sound played when hitting an obstacle or pan
- `powerup.mp3` - Sound played when picking up Level 3 Helmet, Energy Drink, or Flare Gun
- `rage.mp3` - Sound played during Flare Gun / Balayya Mass Rage mode
- `bgm.mp3` - Background battle music (looping)

> **Note:** If any sound file is missing, the game seamlessly falls back to its built-in Web Audio API dynamic synthesizer, so the game will NEVER crash or be silent!
